# Data Sources

## AlphaFold Protein Structure Database

Used for public predicted protein-structure metadata and mmCIF/BCIF files by UniProt accession. Attribution shown in protein structure screens:

`Predicted structure provided by AlphaFold Protein Structure Database. AlphaFold DB data is licensed under CC BY 4.0.`

## Mol*

Mol* `5.10.1` is bundled locally for WebGL molecular visualization in the iOS `WKWebView`. Mol* is MIT licensed; its license text is included at `Molecyou/Resources/MolStar/LICENSE-molstar.txt`.

## UniProt

Used as the accession and protein metadata reference for starter educational content. Bundled summaries are app-authored educational text and separated from runtime code for review.

## HealthKit

Used only for on-device topic relevance. The app never claims HealthKit measures protein activity, expression, folding, or molecular behavior.
